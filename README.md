# ApexVort 平台使用文档

## 1. 平台概述

[ApexVort](https://www.apexvort.com) 是一个面向自动化渗透测试的网络安全靶场平台，提供标准化的测试环境和操作接口。主要用途包括：
- 漏洞检测脚本的快速验证
- 渗透测试工具（含AI/自动化工具）的重复性实验与基线对比
- 自动化渗透测试流水线的集成测试

平台所有测试流量通过VPN专网接入，攻击流量不暴露在公网靶标侧。

## 2. 核心功能

### 2.1 测试集与题目管理
平台内置统一的测试套件，题目按难度、标签、场景等维度分类。用户通过网页端开启一场测试（对应某个测试集）后，可通过界面或API获取题目列表及详细描述。

### 2.2 环境管理
- 支持在同一场次内多次创建和销毁实验环境。
- 环境创建为异步操作，提交后返回状态码202，需轮询查询部署结果。
- 每个用户有资源配额和并发限制，平台自动管控。

### 2.3 VPN接入
用户登录后下载账户专属的OpenVPN配置文件。连接命令示例（Linux）：
sudo openvpn --config /path/to/你的配置.ovpn
连接成功后，方可访问实验环境的内网地址。

### 2.4 结果记录
平台按场次汇总数据，包括实例运行状态、Flag提交记录、每道题目的提交时间线。支持导出基础报告供复盘分析。

### 2.5 API / MCP 接口
提供基于JWT鉴权的REST API和MCP（Streamable HTTP）接口，支持外部脚本、Agent或编排器自动化操作。鉴权方式：在Header中直接使用访问令牌（无需Bearer前缀）。

## 3. MCP 工具列表（供自动化调用）

MCP接口提供以下工具：

- `benchmark_list_challenges`  
  作用：分页列出当前进行中测试的所有题目。  
  参数：page, page_size（可选）

- `benchmark_get_challenge`  
  作用：获取单道题目的详细信息（含描述、提示、附件等）。  
  参数：challenge_id

- `benchmark_create_instance`  
  作用：为实验类题目申请部署一个环境实例。  
  参数：challenge_id  
  返回：HTTP 202，任务ID，后续通过查询获取最终访问信息。

- `benchmark_list_instances`  
  作用：分页列出当前用户活跃的实例列表。  
  参数：page, page_size（可选）

- `benchmark_get_instance`  
  作用：查询指定实例的详细状态（部署中/已就绪）、VPN内网地址和端口。

- `benchmark_destroy_instance`  
  作用：销毁一个已创建的实例，释放资源。

- `benchmark_submit_flag`  
  作用：提交Flag（实验题）或选择题答案（理论题）。  
  参数：challenge_id, flag

## 4. 使用流程（网页端 + 自动化端）

#### 4.1 网页端操作
- 注册并登录账号。
- 在“我的访问”页面获取API Token。
- 在“测试集”页面选择并开启一场测试（开启后方可调用API获取题目列表）。
- 下载VPN配置文件并连接。
- 如需反馈问题，登录后进入“意见反馈”页面提交。

#### 4.2 自动化脚本/Agent集成
- 设置环境变量 AUTOPENTEST_API_TOKEN 为您的Token。
- 通过MCP或REST API调用上述工具，实现自动化选题目、启环境、提交结果。

## 5. 注意事项

- 理论题（选择题/判断题）每场测试中，每道题仅允许提交一次，且提交后不可更改，答错不得分。
- 实例创建后有一定延迟（通常数十秒），请轮询获取实例状态，直到状态变为“ready”后再访问。
- 环境销毁后，对应的内网地址将立即释放，无法再次访问。
- 平台会定期清理长时间闲置的实例，建议使用完毕后主动销毁。
- 意见反馈功能需登录后才能使用。

## 6. 常见问题

Q：连接VPN失败？  
A：确认配置文件下载正确，检查本地网络是否允许UDP 1194端口，或尝试使用TCP模式（修改ovpn文件中的proto）。  

Q：API调用返回401？  
A：请检查Token是否过期（可在网页端重新生成），并确保Header中直接传Token，不加Bearer。  

Q：创建实例后一直处于“deploying”？  
A：可能是资源池繁忙，请等待几分钟后重试；若持续超时，建议销毁后重新创建。  

Q：可以同时运行多少个实例？  
A：受用户配额限制，具体配额可在网页端“我的资源”中查看。
